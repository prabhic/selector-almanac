# Security

## Reporting

If you find a security issue in **this project's code** (app or scripts), please open a [GitHub issue](https://github.com/prabhic/selector-almanac/issues) or email the repo owner via their GitHub profile.

This project is a static index over **public** YouTube and GitHub content. It does not handle user accounts, payments, or private data.

## Scope

- In scope: XSS in the static app, malicious ingest scripts, dependency vulnerabilities in build tooling
- Out of scope: vulnerabilities in Lev Selector's YouTube channel or `lselector/seminar` content
